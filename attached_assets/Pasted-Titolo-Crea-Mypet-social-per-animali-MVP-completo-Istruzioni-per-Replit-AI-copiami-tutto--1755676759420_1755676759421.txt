Titolo: Crea “Mypet” – social per animali (MVP completo)

Istruzioni per Replit AI (copiami tutto):

Crea un’app full-stack chiamata Mypet (monorepo) con:

Frontend: React + Vite, Tailwind CSS.

Backend: Node.js Express + Prisma ORM.

DB: SQLite (file mypet.db).

Auth: Email+password (JWT). Prepara anche OAuth Google (flag disattivato, facile da abilitare).

Storage immagini/video (MVP): salvale su disco in /uploads con multer; astrai in un servizio così poi posso passare a Cloudinary/Supabase cambiando solo l’adapter.

Mappe: Leaflet + OpenStreetMap per la sezione “Smarriti/Ritrovati”.

Brand & UI

Nome app, logo testuale: Mypet.

Stile “Naturalista”: verde dominante, con giallo e azzurro sfumati.

Palette (usa come CSS variables in Tailwind config):

--brand-green: #2E7D32

--brand-green-600: #1B5E20

--brand-yellow: #F4D03F

--brand-azure: #4FC3F7

--bg-gradient: linear-gradient(135deg, #e8f5e9, #e3f2fd 60%)

Applica uno sfondo a tutta l’app con --bg-gradient, card arrotondate, ombre morbide, focus state chiari.

Componenti base: Navbar, Sidebar, Card, Button, Input, Textarea, Avatar, Badge, Modal.

Dark mode opzionale ma non prioritaria.

Requisiti funzionali (MVP)

Registrazione/Login

Email + password, verifica minima (password ≥ 8).

JWT (HttpOnly cookie).

Pagina /auth con tab Login/Signup.

Profilo Utente + Profili Animali

L’utente può creare più Animali (nome, specie, razza, sesso, età, descrizione, foto profilo).

Pagina /me con elenco dei suoi Animali e quick actions (Aggiungi animale, Modifica, Elimina).

Post (foto/video)

Creazione post collegati a un Animale dell’utente.

Campi: media (foto/video), didascalia, tag, visibilità (pubblico/solo follower).

Regola contenuti: vietate foto di sole persone. Implementa:

Checkbox obbligatoria “Confermo che il contenuto mostra un animale”.

Segnalazioni: tasto “Segnala” con motivo “solo persone/abuso/spam”.

Coda moderazione in /admin/moderation (solo admin).

Feed & Interazioni

Feed home con post recenti, like, commenti, follow degli animali e/o dei loro proprietari.

Pagine profilo animale: grid dei post, follower, piccoli insight (conteggio follower/like totali).

Smarriti/Ritrovati (core)

Tipo post: status = normal | lost | found.

Per lost/found: posizione (lat, lng), raggio, data, contatto.

Mappa /lost-found con filtri (distanza, specie, data). Marker cliccabili → dettaglio post.

Notifica in-app se compare un lost/found entro X km dalle preferenze dell’utente (slider su /settings).

Ruoli & Admin

Ruoli: user, vet, shop, shelter, admin.

Richiesta verifica per vet/shop/shelter (upload documento semplice, solo flag per ora).

Dashboard admin con: coda segnalazioni, promozione ruoli, blocco utenti/post.

Ricerca

Search bar per animali, utenti, tag; filtri per specie/razza/area.

Scalabilità futura (stub)

Service mediaStorage con interfaccia e adapter file-system (pronto per Cloudinary).

Event emitter per “postCreated” (hook per email/push in futuro).

Modello dati (Prisma)

Crea gli schemi base:

model User {
  id           String   @id @default(cuid())
  email        String   @unique
  passwordHash String
  displayName  String
  role         Role     @default(USER)
  bio          String?
  avatarUrl    String?
  locationLat  Float?
  locationLng  Float?
  radiusKm     Int?     @default(5)
  animals      Animal[]
  posts        Post[]
  comments     Comment[]
  likes        Like[]
  followers    Follow[] @relation("userFollowers")
  following    Follow[] @relation("userFollowing")
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt
}

model Animal {
  id          String   @id @default(cuid())
  ownerId     String
  owner       User     @relation(fields: [ownerId], references: [id])
  name        String
  species     String   // dog, cat, reptile, etc.
  breed       String?
  sex         String?
  age         String?
  bio         String?
  avatarUrl   String?
  posts       Post[]
  followers   Follow[] @relation("animalFollowers")
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model Post {
  id          String   @id @default(cuid())
  authorId    String   // user who posted
  author      User     @relation(fields: [authorId], references: [id])
  animalId    String
  animal      Animal   @relation(fields: [animalId], references: [id])
  caption     String?
  mediaUrl    String
  mediaType   String   // image|video
  status      PostStatus @default(NORMAL) // NORMAL | LOST | FOUND
  lat         Float?
  lng         Float?
  contact     String?
  isPublic    Boolean  @default(true)
  likes       Like[]
  comments    Comment[]
  reports     Report[]
  createdAt   DateTime @default(now())
}

model Comment {
  id        String   @id @default(cuid())
  postId    String
  post      Post     @relation(fields: [postId], references: [id])
  authorId  String
  author    User     @relation(fields: [authorId], references: [id])
  content   String
  createdAt DateTime @default(now())
}

model Like {
  id        String   @id @default(cuid())
  postId    String
  post      Post     @relation(fields: [postId], references: [id])
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  createdAt DateTime @default(now())
  @@unique([postId, userId])
}

model Follow {
  id         String   @id @default(cuid())
  followerId String?  // user following a user
  followeeId String?  // user being followed
  animalId   String?  // or follow an animal
  createdAt  DateTime @default(now())
  @@index([followerId, followeeId, animalId])
}

model Report {
  id        String   @id @default(cuid())
  postId    String
  post      Post     @relation(fields: [postId], references: [id])
  reporterId String
  reporter   User     @relation(fields: [reporterId], references: [id])
  reason    ReportReason
  note      String?
  status    ReportStatus @default(PENDING)
  createdAt DateTime @default(now())
}

enum Role { USER VET SHOP SHELTER ADMIN }
enum PostStatus { NORMAL LOST FOUND }
enum ReportReason { ONLY_PEOPLE ABUSE SPAM OTHER }
enum ReportStatus { PENDING APPROVED REJECTED }

API principali (Express)

POST /api/auth/signup – crea utente.

POST /api/auth/login – restituisce JWT (HttpOnly cookie).

GET /api/me – dati utente loggato.

POST /api/animals – crea animale (owner = me).

GET /api/animals/:id – dettaglio animale.

POST /api/posts – crea post (upload media).

GET /api/feed – feed generale + filtri.

GET /api/lost-found – lista con bounding box (lat/lng & raggio).

POST /api/posts/:id/like, POST /api/posts/:id/comment

POST /api/posts/:id/report

GET /api/admin/reports – solo admin.

POST /api/follow – follow/unfollow user o animale.

Pagine frontend

/ – Home feed (card con media, autore, animale, like/commenti).

/auth – Login/Signup.

/me – Profilo utente + elenco Animali.

/animal/:id – Profilo animale + post & follower.

/create – Nuovo post (upload). Checkbox “Confermo che si vede un animale”.

/lost-found – Mappa Leaflet con filtri e lista.

/admin/moderation – coda segnalazioni.

Qualità del codice

Organizza il repo in apps/client e apps/server.

Middleware: auth (JWT), rate-limit basilare, validazione input con Zod.

Logger (morgan), gestione errori standard JSON.

Prepara seed dati (2 utenti, 3 animali, 6 post, 1 lost).
